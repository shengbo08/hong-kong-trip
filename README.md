# 香港 3 天 2 夜自由行網站

暫定 9 月從高雄出發的香港自由行手冊，一頁式整理即時香港天氣、TWD/HKD 匯率、航班、住宿、每日行程、景點地圖、餐廳推薦與預算估算。

## 本地開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

## 主要資料

行程、住宿、航班、餐廳、地圖與預算資料集中在：

```txt
src/data/trip.ts
```

目前日期使用 `2026-09-01` 到 `2026-09-03` 作為 9 月暫定行程；確認實際出發日後，更新 `startDate`、`endDate` 與各日 `date` 即可。
